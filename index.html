03 / LIVE DEMOS

動いているもの

入力と反応がつながる瞬間を見せます。

01 / TOOLSPRITE LAB

2.5D立ち絵の構成・ポーズ確認

髪・手・表情などのスプライトパーツを一覧管理し、組み合わせやポーズをブラウザ上で確認。GLBとテクスチャスプライトを、ゲーム実装前に検証します。

2.5DGLBSPRITE
02 / GAMEWEBGL EXPLORATION

街を歩いて違和感を拾う

一人称視点で街を歩き、画面内の対象を調査して記録する探索プロトタイプ。移動、対象判定、ログ、スコープ、時間表示を組み合わせています。

REACTTHREE.JSWEBGL
03 / PROTOTYPE3D INTERACTION

3D空間の見え方と対象選択

階段などの3Dオブジェクトを探索空間に組み込み、プレイヤー視点からの見え方や選択表示の挙動を検証しています。

3D SPACEOBJECT TESTUX
04 / P.N.E.NAME VOICE

「あでのしん」と呼ばれるまで

入力した名前と読みをもとに、作品内で使う名前呼び音声を準備。読みの候補選択、WebGPUによる生成、再生確認までを一つのフローにしています。

TTSWEBGPUVOICE UI
05 / P.N.E.AUDIO INPUT

声と「歯カチ」で操作する

マイク入力をdBで監視し、特定の音響入力をイベントとして検出。入力デバイスの選択、検出状態、再チェックまでを実装しています。

05 / ABOUT

構造を見る目を、
別の領域にも使う。

元ファッションデザイナー。服のデザインとパターン設計から、Web・ゲーム・3D・AIへ。

見た目を作るだけではなく、パーツ同士がどうつながり、どこで破綻し、どうすれば人が触ったときに気持ちよくなるかを考えてきました。その視点を、インタラクティブな体験の設計と実装に使っています。
